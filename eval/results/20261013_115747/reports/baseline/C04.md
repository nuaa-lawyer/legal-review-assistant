# [baseline] C04 数据出境

**输入**: 跨境电商App将中国用户的订单数据和收货地址传输到海外服务器处理

**ground truth**: 中华人民共和国个人信息保护法第三十八条, 数据出境安全评估办法第四条, 中华人民共和国个人信息保护法第三十九条, 中华人民共和国数据安全法第三十一条

# 跨境电商App数据出境合规风险审查报告


## 🔴 高风险项

| 风险点 | 违反法规 | 具体条款 | 风险说明 |
|--------|----------|----------|----------|
| **未进行数据出境安全评估即向海外传输订单数据** | 《数据出境安全评估办法》 | 第4条、第14条 | 跨境电商App将中国用户订单数据（含姓名、电话、地址、消费记录等）传输至海外服务器，属于向境外提供个人信息。若处理个人信息达到100万人以上，或自上年1月1日起累计向境外提供10万人以上个人信息/1万人以上敏感个人信息，必须申报数据出境安全评估，未经评估即传输属严重违规。 |
| **未签订个人信息出境标准合同或未通过认证** | 《个人信息保护法》 | 第38条 | 向境外提供个人信息须满足以下条件之一：通过国家网信部门安全评估、经专业机构认证、签订标准合同。若企业未达到安全评估门槛但未签订标准合同并备案，同样构成违法。 |
| **未取得用户单独同意即出境传输** | 《个人信息保护法》 | 第39条 | 向境外提供个人信息的，应当向个人告知境外接收方的名称、联系方式、处理目的、处理方式、个人信息的种类以及向境外接收方行使权利的方式和程序等事项，并取得个人的**单独同意**。App以概括性隐私政策替代单独同意，属于违规。 |
| **未告知境外接收方详情** | 《个人信息保护法》 | 第39条 | 未明确告知用户境外接收方身份、联系方式、处理目的和方式，剥夺了用户的知情权。 |
| **收货地址属于敏感个人信息，出境保护不足** | 《个人信息保护法》 | 第28条、第29条 | 收货地址结合订单信息可精确定位自然人，属于敏感个人信息（行踪轨迹/精准定位），出境需取得单独同意并履行更严格的保护义务。 |
| **可能违反数据本地化存储要求** | 《网络安全法》 | 第37条 | 关键信息基础设施运营者在中华人民共和国境内运营中收集和产生的个人信息和重要数据应当在境内存储。因业务需要确需向境外提供的，应当按照规定进行安全评估。若该App被认定为CIIO，直接传输即违规。 |


## 🟡 中风险项

| 风险点 | 违反法规 | 具体条款 | 风险说明 |
|--------|----------|----------|----------|
| **隐私政策未明确披露数据出境情况** | 《个人信息保护法》 | 第17条 | 隐私政策中未以显著方式、清晰易懂的语言列明数据出境的目的、方式、接收方等信息，侵犯用户知情权。 |
| **未开展个人信息保护影响评估（PIA）** | 《个人信息保护法》 | 第55条、第56条 | 向境外提供个人信息前，应当事前进行个人信息保护影响评估，并对处理情况进行记录。未开展PIA属于程序性违规。 |
| **未建立便捷的个人信息出境权利行使渠道** | 《个人信息保护法》 | 第50条 | 未建立便捷的个人行使权利的申请受理和处理机制，用户无法有效行使查阅、复制、删除等权利。 |
| **订单数据可能包含重要数据未识别** | 《数据出境安全评估办法》 | 第4条、第8条 | 若订单数据经汇总分析后能反映行业运行情况、经济态势等，可能构成"重要数据"，需单独评估。 |
| **未按规定进行年度数据出境安全自评估** | 《数据出境安全评估办法》 | 第14条 | 通过安全评估后，若出境目的、方式、范围等发生变更，或出现影响出境数据安全的情形，应当重新申报评估。 |
| **海外服务器所在国法律环境风险** | 《个人信息保护法》 | 第41条 | 境外接收方所在国家/地区的法律可能要求其向本国政府提供数据，企业需评估并告知用户该风险。 |

| **P2（60日内）** | 建立数据分类分级制度 | 区分一般个人信息、敏感个人信息、重要数据，对不同类别数据实施差异化出境管控 | 《数据安全法》第21条 |
| **P2（60日内）** | 建立用户权利响应机制 | 设立便捷的申请受理渠道，确保用户可查阅、复制、删除其出境数据，响应时限不超过15个工作日 | 《个人信息保护法》第50条 |
| **P2（60日内）** | 评估境外接收方所在国法律环境 | 评估境外服务器所在国法律是否要求数据本地留存或政府调取，必要时签订补充协议或调整服务器位置 | 《个人信息保护法》第41条 |
| **P3（持续）** | 建立数据出境动态监测机制 | 定期审计数据出境流量、接收方变更情况，发生变更时重新申报评估或重新签订标准合同 | 《数据出境安全评估办法》第14条 |


## ⚠️ 总结

**核心结论：** 该跨境电商App将中国用户订单数据和收货地址传输至海外服务器的行为，**在未完成法定合规程序的情况下，存在严重违法风险**。

**三大核心问题：**

1. **程序缺失**：未申报安全评估、未签订标准合同、未取得单独同意，三项法定前置程序均未履行，属于典型的"裸奔式"数据出境。

2. **数据敏感度高**：订单数据+收货地址的组合可精准识别特定自然人，涉及敏感个人信息，法律保护要求更高，违法后果更严重。

3. **处罚风险大**：依据《个人信息保护法》第66条，违法处理个人信息最高可处**5000万元以下或上一年度营业额5%以下**罚款，并可能责令暂停相关业务、停业整顿、吊销营业执照；直接责任人员可处10万-100万元罚款，并禁止一定期限内担任相关职务。

**建议：** 立即启动合规整改，优先完成安全评估申报和单独同意获取，在合规程序完成前暂停相关数据出境行为，避免监管处罚和商誉损失。
