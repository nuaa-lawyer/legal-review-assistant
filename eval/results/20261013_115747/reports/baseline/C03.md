# [baseline] C03 未成年人信息

**输入**: 面向中小学生的在线教育平台，收集学生姓名、年龄、成绩、位置信息，并据此推送个性化学习内容

**ground truth**: 中华人民共和国个人信息保护法第三十一条, 中华人民共和国未成年人保护法第七十四条, 中华人民共和国未成年人保护法第七十二条, 互联网信息服务算法推荐管理规定第十八条

# 在线教育平台合规风险审查报告

> **审查对象**：面向中小学生的在线教育平台（收集学生姓名、年龄、成绩、位置信息，用于个性化学习内容推送）
> **审查视角**：法律合规风险
> **审查日期**：2026年4月


## 🔴 高风险项

| 风险点 | 违反法规 | 具体条款 | 风险说明 |
|--------|----------|----------|----------|
| **未取得监护人单独同意即收集未成年人个人信息** | 《中华人民共和国个人信息保护法》 | 第31条第1款 | 平台面向中小学生（均为未成年人），收集姓名、年龄、成绩、位置等信息，必须取得父母或其他监护人的**单独同意**。若仅由学生本人点击"同意"或默认勾选，属于严重违法。 |
| **收集不满十四周岁儿童个人信息未制定专门处理规则** | 《中华人民共和国个人信息保护法》 | 第31条第2款 | 中小学生中大量用户不满14周岁，平台必须制定**专门的儿童个人信息处理规则**并进行显著告知，否则构成违法。 |
| **收集位置信息可能构成过度收集** | 《中华人民共和国个人信息保护法》 | 第6条（最小必要原则） | 个性化学习内容推送通常**不需要精确位置信息**。若平台收集GPS精确定位而非仅IP粗定位，且无法证明与学习内容推送的必要关联，违反最小必要原则。 |
| **处理敏感个人信息（不满十四周岁未成年人信息）未取得单独同意并履行告知义务** | 《中华人民共和国个人信息保护法》 | 第28条、第29条 | 不满十四周岁未成年人的个人信息属于**敏感个人信息**，处理此类信息需具有特定目的和充分必要性，取得监护人单独同意，并向其告知处理目的、方式及必要性。 |
| **未进行个人信息保护影响评估（PIA）** | 《中华人民共和国个人信息保护法》 | 第55条第（一）项、第（三）项 | 处理敏感个人信息、向未成年人推送个性化信息前，必须事前进行个人信息保护影响评估并记录处理情况。未做PIA即上线运营属违法。 |
| **利用未成年人个人信息进行自动化决策推送** | 《中华人民共和国个人信息保护法》 | 第24条第1款、第3款 | 通过自动化决策（算法推荐）向未成年人推送个性化内容，应保证决策透明度和结果公平公正，不得对未成年人在交易条件上实行不合理差别待遇。同时，推送信息**不得诱导未成年人沉迷**。 |
| **可能违反未成年人网络保护关于沉迷防治的规定** | 《未成年人网络保护条例》 | 第43条、第44条 | 平台以个性化推荐方式向未成年人推送学习内容，若算法设计不当导致过度使用或变相诱导沉迷（如无限滚动、强提醒），违反未成年人网络保护义务。 |
| **未落实儿童个人信息网络保护专门规定** | 《儿童个人信息网络保护规定》 | 第9条、第10条、第13条 | 收集、使用、转移儿童个人信息须取得监护人同意；应设置专门的儿童个人信息保护规则和用户协议；委托第三方处理时须进行安全评估。 |
| **未履行数据安全保护义务（成绩、位置等敏感数据）** | 《中华人民共和国数据安全法》 | 第27条、第29条 | 平台掌握大量未成年人成绩、位置等敏感数据，须建立数据安全管理制度、开展风险评估、采取加密等安全措施。若发生数据泄露未及时告知用户和主管部门，将面临重罚。 |
| **可能构成超范围收集与学习无关的信息** | 《中华人民共和国个人信息保护法》 | 第6条 | 若平台收集位置信息用于非教学目的（如广告投放、用户画像商业化），则超出必要范围，属于违法处理。 |


## 🟡 中风险项

| 风险点 | 违反法规 | 具体条款 | 风险说明 |
|--------|----------|----------|----------|
| **隐私政策未以显著、清晰方式向未成年人及监护人告知** | 《个人信息保护法》 | 第17条 | 隐私政策须以简明易懂的语言向未成年人及其监护人告知处理目的、方式、种类、保存期限等。若使用晦涩法律术语或隐藏于多层链接中，告知不充分。 |
| **未提供便捷的撤回同意和注销账号方式** | 《个人信息保护法》 | 第15条 | 监护人应有权随时撤回同意，平台须提供便捷的撤回方式。若注销流程复杂或设置不合理障碍，属违规。 |
| **未明确个人信息保存期限** | 《个人信息保护法》 | 第19条 | 平台须明确成绩、位置等信息的保存期限，到期后应删除或匿名化。若无限期保存，违反最短必要期限原则。 |
| **个性化推送未提供"非个性化"选项** | 《个人信息保护法》 | 第24条第2款 | 通过自动化决策推送信息时，应同时提供不针对个人特征的选项或便捷拒绝方式。若平台强制个性化推送且无法关闭，违规。 |
| **未建立个人信息泄露应急预案和通知机制** | 《个人信息保护法》 | 第57条 | 发生或可能发生个人信息泄露、篡改、丢失的，应立即采取补救措施并通知履行个人信息保护职责的部门和个人。 |
| **未指定个人信息保护负责人** | 《个人信息保护法》 | 第52条 | 处理个人信息达到国家网信部门规定数量的处理者，应指定个人信息保护负责人并公开联系方式。 |
| **跨境传输风险（若使用境外服务器或第三方SDK）** | 《个人信息保护法》 | 第38条、第39条 | 若平台使用境外服务器、境外分析工具（如Google Analytics）等，可能涉及数据出境，须通过安全评估、标准合同或认证，并取得监护人单独同意。 |
| **未对第三方SDK进行安全管理** | 《个人信息保护法》 | 第21条 | 若平台嵌入第三方SDK（如统计、广告、推送），须与受托方约定处理目的、期限、方式等，并进行监督。未告知用户即嵌入SDK属违规。 |
| **未落实网络安全等级保护制度** | 《中华人民共和国网络安全法》 | 第21条 | 平台作为网络运营者，须履行网络安全等级保护义务。若未定级备案，存在合规风险。 |

## ⚠️ 总结

本平台面向中小学生收集姓名、年龄、成绩、位置信息并用于个性化推送，属于**处理未成年人个人信息和敏感个人信息的高风险场景**，合规风险等级为**高**。核心问题集中在以下五个方面：

1. **监护人同意缺失**：未取得监护人单独同意即处理未成年人信息，是最严重的合规漏洞，可能面临最高**5000万元或上一年度营业额5%** 的罚款（《个人信息保护法》第66条）。

2. **敏感信息处理不规范**：不满14周岁未成年人信息属于敏感个人信息，需履行更严格的告知同意和PIA义务。

3. **位置信息收集必要性存疑**：个性化学习推送通常不需要精确位置，存在过度收集风险。

4. **自动化决策对未成年人的特殊保护不足**：算法推送需防止诱导沉迷，须提供非个性化选项。

5. **数据安全制度不健全**：成绩、位置等敏感数据缺乏加密、审计和应急机制。

**建议**：立即启动P0级整改（监护人同意机制、儿童处理规则、PIA、位置信息必要性评估），并在30日内完成全部P1-P2整改。同时建议聘请外部法律顾问进行专项合规审计，并与当地网信部门主动沟通备案事宜，以降低行政处罚和民事赔偿风险。

> **特别提示**：2024年1月1日起施行的《未成年人网络保护条例》进一步强化了平台责任，违规可能面临责令暂停相关业务、停业整顿、关闭网站等严厉处罚。
