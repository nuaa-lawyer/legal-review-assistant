## 🔴 高风险项

| 风险点 | 违反法规 | 具体条款 | 风险说明 |
|--------|----------|----------|----------|
| 将行程轨迹（行踪轨迹）共享给广告联盟用于精准投放 | 《中华人民共和国个人信息保护法》 | 第28条：行踪轨迹属于敏感个人信息；第29条：处理敏感个人信息应取得个人的**单独同意** | 行程轨迹可精确还原用户住址、工作地、出行规律、就医记录、社交关系等，属于敏感个人信息。将其用于广告投放远超原始收集目的，且未取得单独同意，构成严重违法 |
| 将常用地址（家庭/公司地址）共享给广告联盟 | 《中华人民共和国个人信息保护法》 | 第28条（敏感个人信息）、第23条（向第三方提供须单独同意并告知接收方信息） | 常用地址直接指向自然人居住和工作场所，结合行程轨迹可完整还原个人生活全貌，属于敏感个人信息，共享行为违法 |
| 用户协议中未单独说明共享行为 | 《中华人民共和国个人信息保护法》 | 第17条：应真实、准确、完整告知处理目的、方式、种类、保存期限等；第23条：向第三方提供应告知接收方名称、联系方式、处理目的、处理方式和个人信息种类，并取得**单独同意** | 未在用户协议中单独列明共享给广告联盟的目的、数据类型、接收方身份，属于告知义务缺失，使用户在不知情情况下被共享信息 |
| 未经单独同意向第三方提供个人信息 | 《中华人民共和国个人信息保护法》 | 第23条：向其他个人信息处理者提供其处理的个人信息的，应当向个人告知接收方的名称或者姓名、联系方式、处理目的、处理方式和个人信息的种类，并取得个人的**单独同意** | 将行程轨迹和常用地址共享给广告联盟，属于向第三方提供个人信息，必须取得单独同意，不能以概括性用户协议替代 |
| 超出原始收集目的使用个人信息 | 《中华人民共和国个人信息保护法》 | 第6条：处理个人信息应当具有明确、合理的目的，并应当与处理目的直接相关，采取对个人权益影响最小的方式 | 用户使用网约车App的目的是出行服务，将行程数据用于广告投放与原始目的无直接关联，违反目的限制原则 |
| 未进行个人信息保护影响评估 | 《中华人民共和国个人信息保护法》 | 第55条：向第三方提供个人信息、处理敏感个人信息、自动化决策等情形，应当事前进行个人信息保护影响评估并记录处理情况 | 向广告联盟共享敏感个人信息用于精准投放，属于必须进行影响评估的情形，未评估即违法 |
| 可能构成自动化决策中的差别待遇 | 《中华人民共和国个人信息保护法》 | 第24条：利用个人信息进行自动化决策，应当保证决策的透明度和结果公平、公正，不得对个人在交易价格等交易条件上实行不合理的差别待遇 | 基于行程轨迹和地址进行精准广告投放，若涉及差异化定价或歧视性推送，违反自动化决策规定 |
| 违反《常见类型移动互联网应用程序必要个人信息范围规定》 | 《常见类型移动互联网应用程序必要个人信息范围规定》 | 第5条：网络约车类App必要个人信息为注册用户移动电话号码、乘车人出发地、到达地、位置信息、行踪轨迹；**超出必要范围收集/使用即违规** | 行程轨迹和地址信息仅可用于保障出行服务，共享给广告联盟超出必要个人信息使用范围 |

## ⚠️ 总结

**核心结论：该产品功能存在严重合规缺陷，属于典型的敏感个人信息违规共享行为，面临极高法律风险。**

### 主要问题

1. **敏感个人信息被滥用**：行程轨迹和常用地址均属于《个人信息保护法》第28条明确列举的敏感个人信息，将其共享给广告联盟用于精准投放，完全偏离了网约车服务的原始目的，违反目的限制原则和最小必要原则。

2. **"单独同意"缺失是致命缺陷**：根据《个人信息保护法》第23条和第29条，向第三方提供敏感个人信息必须取得用户的**单独同意**，且不能以概括性用户协议替代。本案中用户协议未单独说明，属于明知故犯的合规漏洞。

3. **告知义务全面缺失**：未告知接收方身份、共享目的、数据种类、保存期限，用户完全处于信息不对称状态，无法行使知情权和决定权。

### 潜在法律后果

| 后果类型 | 具体内容 |
|----------|----------|
| 行政处罚 | 根据《个人信息保护法》第66条，情节严重的可处**5000万元以下或上一年度营业额5%以下**罚款，并责令暂停相关业务、停业整顿、吊销业务许可 |
| 民事赔偿 | 用户可依据《个人信息保护法》第69条提起侵权诉讼，要求赔偿损失 |
| 刑事责任 | 若情节严重，可能触犯《刑法》第253条之一"侵犯公民个人信息罪" |
| 声誉损失 | 一旦曝光，将引发监管关注和公众信任危机，严重影响App用户留存 |
| 应用下架 | 监管部门可依据《App违法违规收集使用个人信息行为认定方法》要求应用商店下架整改 |

### 建议

**立即下线该共享功能**，在完成单独同意机制建设、隐私政策修订、PIA评估和DPA签订之前，不得恢复任何形式的行程数据广告共享。同时建议聘请外部法律顾问进行全面的数据合规审计，排查是否存在其他类似违规共享行为。
