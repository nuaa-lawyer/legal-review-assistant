## 🎯 项目概述

**法审助手**是一款面向产品经理和法务人员的AI合规审查系统。输入产品功能描述（如"社交App允许用户查看附近100米内其他用户位置"），系统自动输出结构化的合规风险报告，包含：风险点识别、法规依据匹配、修改建议生成。

### 核心亮点

- **RAG架构**：检索增强生成，确保每条风险分析都有真实法规依据，杜绝大模型"幻觉"
- **多Agent协作**：分类Agent → 检索Agent → 报告Agent，三个独立LLM调用分工协作
- **语义检索**：基于 `bge-large-zh-v1.5` 的向量化检索，覆盖15部核心法规、2015条条款
- **零成本运行**：使用免费API（SiliconFlow + DeepSeek），学生友好

## 🏗️ 技术架构

```
用户输入
   │
   ▼
┌─────────────────────────────────────────────────┐
│  🔍 Agent 1: 风险分类器 (RiskClassifier)         │
│  识别: 数据类型 | 处理行为 | 风险领域 | 风险等级  │
│  输出: 结构化JSON分类结果                        │
└─────────────────────┬───────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────┐
│  📚 Agent 2: 法规检索器 (LegalRetriever)         │
│  多角度查询生成 → 语义向量检索 → LLM精选+适用性分析│
│  输出: Top-5法条 + 适用原因                      │
└─────────────────────┬───────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────┐
│  📝 Agent 3: 报告生成器 (ReportGenerator)        │
│  汇总分类结果 + 法条依据 → 结构化合规报告         │
│  输出: 风险表格 | 修改建议 | 总结                │
└─────────────────────┬───────────────────────────┘
                      │
                      ▼
              结构化合规风险报告 (Markdown)
```

### 技术栈

| 组件 | 方案 | 说明 |
|------|------|------|
| LLM | DeepSeek-V3 | 中文法律文本理解和生成，极低成本 |
| Embedding | bge-large-zh-v1.5 (SiliconFlow) | 1024维中文语义向量，免费额度 |
| 向量检索 | NumPy + 余弦相似度 | 零依赖，适合MVP规模 |
| 法规处理 | python-docx | 自动解析Word文档，按条款拆分 |
| 前端 | 自定义HTML + Streamlit | 本地零依赖 / 云端展示 |
| Agent框架 | 自实现编排器 | 轻量级，无需LangChain等重依赖 |

## 🚀 快速开始

### 1. 环境准备

```bash
pip install python-docx numpy openai python-dotenv
```

### 2. 配置API Key

```bash
cp .env.template .env
# 编辑 .env，填入 DeepSeek API Key 和 SiliconFlow API Key
```


### 3. 构建法规索引

```bash
python main.py --build
# 解析Word法规 → 生成向量 → 保存索引
```

### 4. 启动服务

```bash
# 本地Web界面 (零依赖)
python src/ui/server.py
# 浏览器打开 http://localhost:8080
```

## 🧪 示例输出

**输入**: "社交App允许用户查看附近100米内其他用户实时位置"

**Agent执行过程**:
```
🔍 风险分类器 (1.2s) → 识别: 位置信息, 社交网络, high风险
📚 法规检索器 (2.5s) → 匹配: 个人信息保护法第6,13,28条
📝 报告生成器 (4.0s) → 生成结构化报告
总耗时: 7.7s
```

**报告片段**:

### 🔴 高风险项
| 风险点 | 违反法规 | 具体条款 | 风险说明 |
|--------|----------|----------|----------|
| 未经同意收集位置信息 | 个人信息保护法 | 第13条 | 位置信息属于敏感个人信息，需取得用户单独同意 |
| 超出最小必要范围 | 个人信息保护法 | 第6条 | 实时显示100米内其他用户位置可能超出服务必需 |

### 📝 修改建议
1. **将实时位置改为模糊距离显示**（如"附近"而非"100米内"）
2. **增加用户隐私设置开关**（允许用户选择是否可见、可见范围）
3. **首次使用时弹窗获取明确同意**（单独告知+用户主动勾选）
